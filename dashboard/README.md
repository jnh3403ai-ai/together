# RESCUE BAND · 구조대원 안전 관제

소방·경찰 긴급 출동 대원의 **안전을 실시간으로 관제**하는 웹앱입니다.
대원이 착용한 **구조팔찌**로부터 심박·낙상·배터리·위치를 수집해 종합상황실에서 모니터링합니다.
순수 HTML/CSS/JavaScript로 작성되어 별도 빌드 없이 **GitHub Pages에 바로 배포**할 수 있습니다.

## 두 가지 버전
동일한 디자인·데이터(`js/data.js`)를 공유하는 두 개의 화면 구성이 제공됩니다.

| 버전 | 진입점 | 레이아웃 |
|------|--------|----------|
| **모바일** | [`index.html`](index.html) | 핸드폰 비율 · 하단 탭바 |
| **PC(데스크톱)** | [`pc/index.html`](pc/index.html) | 좌측 사이드바 · 넓은 그리드 |

## 대상 사용자 / 상황
- 소방·경찰 종합상황실 **관제요원**
- 출동 중인 대원의 위험 징후(낙상·심박 이상·SOS)를 즉시 감지·대응

## 화면 구성 (하단 탭)
| 탭 | 내용 |
|----|------|
| **홈** | 위험경보·출동중·대기·전체 통계, 출동 파트 편성 기준, 진행 중 출동, 주의 필요 대원 |
| **대원** | 검색·필터(전체/위험/출동중/대기/복귀), 대원별 실시간 상태 카드 |
| **이력** | 신고·구조 출동 이력 아카이브 |
| **알림** | 낙상·SOS·배터리·복귀 등 실시간 경보 |

상단바: 알림 · **다크 모드 토글** · 설정(개인 설정)

### 대원 상세 (카드 탭 시)
한 대원 카드를 열면 다음 정보를 통합 제공합니다.
- **팔찌·기기 상태** — 모델·펌웨어·신호·배터리·동기화
- **응급 의료 정보** — 혈액형·기저질환·알레르기·복용약물·현장 지침
- **보호자·비상 연락** — 관계·연락처
- **실시간 위치** — 실제 지도(OpenStreetMap/Leaflet) 위에 위치 핀·주소

## 출동 유형별 편성 인원
| 유형 | 편성 인원 | 역할 |
|------|-----------|------|
| 구급 출동 | 3명 | 환자 이송·응급처치 |
| 화재 출동 | 10명 | 화재 진압·인명 대피 |
| 구조 출동 | 6명 | 인명 구조·수색 |

## 디자인
- 키워드: Modern · Clean · Professional · Medical · Government Service
- 라이트/다크 테마(상단 달 아이콘 또는 설정에서 전환), 선택은 브라우저에 저장
- 과한 그라데이션·이모지·복잡한 장식 배제, 직관적 정보 계층

## 실행 방법
정적 사이트이므로 로컬 서버로 확인합니다.
```bash
npx serve .
# 또는
python -m http.server 8000
```
브라우저에서 `http://localhost:8000` 접속.

## GitHub Pages 배포
1. 이 폴더 내용을 저장소에 push
2. Settings → Pages → Branch를 `main` / root로 지정
3. 배포된 `https://<user>.github.io/<repo>/` 접속
   - `.nojekyll` 파일이 포함되어 Jekyll 처리를 건너뜁니다.

## 기술 메모
- **바닐라 JS/CSS** — Google Fonts, 지도(Leaflet + OpenStreetMap) 외 프레임워크·번들러 없음
- 해시 기반 라우팅(`#/route`)
- 데이터(`js/data.js`)는 목업이며, 실제 배포 시 백엔드 API로 교체 전제
- 모바일·PC 버전이 **같은 `js/data.js`를 공유**(PC는 `../js/data.js` 참조)

## 파일 구조
```
index.html          # 모바일 버전
css/styles.css
js/
  data.js           # 목업 데이터 (대원·이력·알림) — 두 버전 공유
  app.js            # 모바일 라우팅 + 렌더링 + 테마
pc/                 # PC(데스크톱) 버전
  index.html        # 사이드바 셸
  css/styles.css
  js/app.js
.nojekyll
README.md
```

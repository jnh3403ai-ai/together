# RESCUE BAND

> 재난 현장 대응요원용 **스마트 구조 요청 팔찌** 제품 소개 브랜드 웹사이트
> 컴패니언 앱 **"구조대원 안전 관제"**와 통일한 라이트·블루 디자인 시스템

화재·붕괴·침수·유독가스 누출 등 위험한 재난 현장에 투입되는 소방관과 구조대원의 생존 가능성을 높이기 위한, **화면 없는 스마트 구조 요청 팔찌**를 소개하는 원페이지 홍보 웹사이트입니다.

## 특징

- 위험 감지 → 판단 → 알림 → 전송으로 이어지는 제품 작동 방식 설명
- SOS 버튼, 낙상·충격 감지, 정밀 위치 추적, 생체·환경 센서 등 핵심 기능 소개
- 인터랙티브 센서 핫스팟, 작동 단계 탭, 스크롤 등장 애니메이션
- SVG 기반 건물 평면도 위치 안내, 시나리오 타임라인
- 일반 스마트워치와의 비교 표
- 완전 반응형 (PC / 태블릿 / 모바일)

## 파일 구조

```
index.html   화면 구조 (시맨틱 HTML)
style.css    스타일 (다크 산업 디자인 · 안전 오렌지/경고 레드)
script.js    인터랙션 (내비게이션, 탭, 핫스팟, reveal 애니메이션)
assets/      이미지 등 정적 자원 (현재는 CSS/SVG 그래픽으로 대체)
```

## 실행

`index.html` 파일을 브라우저로 열기만 하면 됩니다. 별도의 빌드 과정이 없어 GitHub Pages에 그대로 배포할 수 있습니다.

## 안내

본 웹사이트와 제품은 실제 의료기기 또는 인증된 재난 구조 장비가 아닌 **제품 콘셉트 및 교육·발표용 프로토타입**입니다. 사용된 프레임워크·라이브러리·외부 API·서버는 없습니다. (순수 HTML / CSS / JavaScript)
